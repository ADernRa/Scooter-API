Асинхронний RESTful API для безстанційного шерингу електросамокатів. Побудований на сучасному стеку FastAPI та SQLAlchemy 2.0 з підтримкою повноцінної JWT-авторизації та рольової моделі (User / Admin).

## :rocket: Стек технологій
- **FastAPI** - швидкий асинхронний вебфреймворк.
- **SQLAlchemy 2.0 (Asyncio)** - ORM для безпечної роботи з СУБД.
- **Alembic** - міграція бази даних
- **Pydantic v2 & Pydantic-Settings** - сувора валідація конфігурації та даних.
- **JWT (JSON Web Tokens) & Passlib** - безпечна аутентифікація, хешування паролів та захист маршрутів.
- **Uvicorn** - ASGI вебсервер.

## Як запустити проєкт локально

### 1. Клонування репозиторію
Завантажте проєкт з GitHub та перейдіть у його кореневу директорію:
```bash
git clone https://github.com/ADernRa/Scooter-API-FastAPI-SQLalchemy-
cd Scooter-API-FastAPI-SQLalchemy-
```

### 2. Налаштування віртуального оточення
Створіть та активуйте віртуальне оточення Python:
```bash
# Для Windows:
python -m venv venv
venv\Scripts\activate

# Для macOS/Linux:
python3 -m venv venv
source venv/bin/activate
```

### 3. Встановлення залежностей

Встановіть необхідні бібліотеки для роботи додатка:

```bash
pip install fastapi uvicorn pydantic-settings sqlalchemy asyncpg
```

### 4. Налаштування змінних оточення

У кореневій папці проєкту створіть файл **.env** і додайте в нього такі налаштування:

```env
DATABASE_URL=postgresql+asyncpg://postgres:your_password@localhost:5432/scooter_api
SECRET_KEY=secret_key
ADMIN_TOKEN=secret_token
DEBUG=True
```

### 5. Викрористання міграцій бази даних (Обов'язково)

Створіть структуру таблиць у вашій PostgreSQL за допомогою Alembic перед запуском сервера:

```bash
alembic upgrade head
```

### 6. Запуск сервера

Запустіть сервер розробки з автоматичним перезавантаженням при зміні коду:

```bash
uvicorn src.main:app --reload
```

## :book: Документація API

Після запуску сервера інтерактивна документація Swagger UI з усіма схемами запитів та можливістю тестування ендпоінтів у реальному часі буде доступна за адресою:
 **`http://127.0.0/docs`**

### Основні можливості (Ендпоінти):
- **Авторизація (`/api/v1/authorization`)**:
1. Реєстрація нових користувачів.
2. Аутентификация и выдача JWT-токенов.
- **Для користувачів (`/api/v1/user`)**: 
1. Виведення доступних самокатів на конкретній точці
2. Оренда самоката та завершення поїздки в будь-якій локації на вулиці з оновленням заряду батареї.
3. Автоматичне збереження поїздок, де вказан час початку та кінця, а також вартість всієї поїздки
- **Для адміністрації (`/api/v1/admin`)** Захищені ендпоінти, що вимагають передачі секретного заголовка `Admin-Token`:
1. Переглядати повну інформацію про всі станції
2. Дозволяють створювати нові станції, самокати та персонал
3. Видаляти елементи та проводити часткове оновлення даних станцій, самокатів, персоналу
